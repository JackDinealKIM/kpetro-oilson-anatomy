# 「오일손」 — 주유기 옆 QR 한 장, 버튼 세 개

2026년 K-Petro 대국민 혁신 아이디어 공모전(AI·데이터 혁신) 출품작 「오일손」의 시연 페이지입니다.

**라이브 — https://jackdinealkim.github.io/kpetro-oilson-anatomy/**

새로 설치하는 장비가 없습니다. 기존 주유기 옆에 QR 스티커 한 장을 붙이고, 손님이 휴대폰으로 찍으면 앱 설치 없이 열리는 웹 화면에서 세 가지를 고릅니다.

- ① **주유 안내** — 6단계 큰 글씨 안내, 단계마다 음성으로 읽어 줌
- ② **직원 도움 요청** — 원터치. 야간·무인 주유소는 지역본부 당직·원격관제로 연결
- ③ **이상 신고** — 정량 미달·가짜석유 의심을 고르고 사진·말로 남기면 접수번호와 함께 관할 지역본부로 배정

## 파일

- `index.html` — 단일 파일. 외부 라이브러리·폰트·이미지 의존 0건, 설치 없이 브라우저에서 열립니다.
- `shots/` — 데스크톱·모바일·휴대폰 화면별 캡처(제출용 참고자료 PDF의 그림 원본).
- `shots/archive-console/` — 이전 "현장 콘솔" 모형(하드웨어 설치형) 캡처. 새 버전에서는 쓰지 않습니다.

## 동작

- 주유기 그림의 QR 스티커를 누르면 스캔 장면이 지나간 뒤 휴대폰 화면이 열립니다(시연).
- 휴대폰 화면 안에서 ①·②·③을 눌러 각 흐름을 끝까지 따라갈 수 있습니다.
- ①은 `이전`/`다음`으로 6단계를 넘기고, `소리로 듣기`를 켜면 단계마다 음성으로 읽어 줍니다(브라우저 음성 합성, 미지원 기기는 버튼 숨김).
- 키보드: `Esc` 처음으로, ① 화면에서 `←`/`→` 단계 이동.
- `동작 줄이기` 설정을 켜면 애니메이션을 멈춥니다.

Pages 소스는 **`gh-pages` 브랜치 / (root)**, `main`은 원본 소스 브랜치입니다. 수정 후에는 `git push origin main && git push origin main:gh-pages`로 함께 올립니다.

수치(6단계·외국어 4종·10개 지역본부·300→1,000개소·대상 1,090만 명)는 제출 제안서와 같은 값입니다.
